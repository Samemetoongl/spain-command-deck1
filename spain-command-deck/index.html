    Wake up with your iPhone locked

    Set a Clock alarm for your wake-up time. In Shortcuts → Automation → Alarm → Is Stopped, select that alarm and choose Run Immediately. Add Text with your greeting, then Speak Text. You can also run your Open SPAIN shortcut afterward to update battery and open the deck.

    The web alarm runs while the deck is visible. Clock and Shortcuts handle waking with the screen locked. The deck briefing uses the tasks and events saved here.
